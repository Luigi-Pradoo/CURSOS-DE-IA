Introdução a Machine LearningEste documento serve como um guia consolidado da Aula 3 sobre os fundamentos, processos e algoritmos de Machine Learning.  Módulo 1: A Essência do Machine LearningA base do Machine Learning é a transição da programação por regras explícitas para o aprendizado derivado puramente de dados históricos. De acordo com Tom Mitchell, um programa aprende se seu desempenho em uma tarefa melhora através da experiência.  Supervisionado: O modelo mapeia matematicamente a relação entre as features (perguntas) e o target (respostas corretas).  Não Supervisionado: O modelo recebe dados crus sem respostas e procura autonomamente por padrões e grupos ocultos.  Por Reforço: Um agente atua em um ambiente, utilizando tentativa e erro focado em recompensas e penalizações.  Overfitting: O modelo decora os ruídos do treino, apresentando 100% de acurácia no treinamento, mas destruindo-se nos testes.  Underfitting: O modelo é demasiadamente simples e ignora as complexidades reais dos dados.  O equilíbrio fundamental do Machine Learning foca no trade-off entre Viés (assunções incorretas) e Variância (sensibilidade alta do modelo):  $$Erro=Vies^{2}+Vari\hat{a}ncia+Erro_{Irredutivel}$$  Módulo 2: Domínio e Dados ClássicosBases clássicas servem de benchmark prático para algoritmos no scikit-learn. Módulo 3: Feature EngineeringTransformar os dados brutos de entrada ajuda a evitar a Maldição da Dimensionalidade e melhora a eficiência do processamento descartando recursos que formam "ruídos".  Min-Max Scaler: Reduz os dados de uma coluna de forma rígida entre limites de 0 e 1.  Standard Scaler (Padronização): Converte a feature para o Z-Score, atribuindo uma média igual a 0 e desvio padrão 1.  Robust Scaler: Ignora os extremos usando a Mediana e o Intervalo Interquartil (IQR), prevenindo distorção por outliers.  Pipelines: Objetos que empacotam passos simultâneos e evitam o Data Leakage aplicando transformações estritamente baseadas nos limites fatiados de treino.  ColumnTransformers: Divide o processamento pelo nome das colunas aplicando sub-pipelines focados no tipo de dado, concatenando tudo automaticamente no final.  SMOTE: Cria pontos matemáticos artificiais entre um exemplo da classe minoria e os seus vizinhos a fim de resolver desbalanceamento.  Módulo 4: Validação de ModelosTécnicas indispensáveis para blindar a análise contra ilusões de acurácia.  Base de Treino: Fatiada para a exaustão de cálculo de gradientes e pesos.  Base de Validação: Fatiada focada no ajuste de hiperparâmetros limpos de maneira que os parâmetros não se viciem para o teste final.  Base de Teste: O teste definitivo do projeto que permanecerá intocado e usado apenas uma vez.  K-Fold Cross-Validation: Anula a sorte dividindo os blocos em pedaços e re-testando cada fatia consecutivamente, tirando uma média final.  Stratified K-Fold: Força cada pedaço da validação cruzada a respeitar exatamente a mesma distribuição e proporção de classes globais.  Módulo 5: Algoritmos PreditivosPrincipais fórmulas e abordagens que sustentam os aprendizados:AlgoritmoNatureza e DefiniçãoRegressão LinearFórmula aditiva base que minimiza resíduos, mas que pode quebrar estabilidade de peso diante de multicolinearidade severa.  Lasso (Penalidade L1)Uma otimização de regularização que força geometricamente coeficientes e características inúteis a caírem para exatamente zero.  KNN (Lazy Learning)Modelo que usa memória RAM para salvar dados e classificar novos exemplos votando nos "K" vizinhos vetorialmente mais próximos.  Regressão LogísticaClassificador padrão da indústria que usa a Função Sigmoide para espremer valores contínuos numa probabilidade fechada entre 0 e 1.  Support Vector Machines (SVM)Busca encontrar uma rua (hiperplano) larga que maximize a margem, e usando o Truque do Kernel, consegue resolver separações não-lineares indo para camadas geométricas 3D.  Random ForestUm "Ensemble" que cria florestas de árvores através de Bootstrap (sorteio repetido de amostras e colunas), garantindo estabilidade via cancelamento de erros isolados da árvore nativa.  XGBoost (Gradient Boosting)Ensambles de arquitetura paralela e punitiva (serial), onde uma segunda árvore aprende com base nos erros e não no alvo da sua árvore antecessora.  Módulo 6: Métricas de AvaliaçãoA validação traduz as abstrações matemáticas em pontuações de negócio reais.  Precisão: Divide o volume de Verdadeiros Positivos pelo agrupamento total de (Verdadeiros Positivos + Falsos Positivos).  Recall: Divide os Verdadeiros Positivos pelo agrupamento de (Verdadeiros Positivos + Falsos Negativos), almejando focar puramente em alvos importantes ignorados.  F1-Score: Resume e combina a Média Harmônica entre a Precisão e o Recall, perfeita para bases altamente desbalanceadas.  Curva ROC e AUC: Mede separabilidade através da intersecção da Taxa de Verdadeiros e Falsos Positivos ao variar diferentes limiares (Thresholds).  Curva Precisão-Recall: Exibe o ganho verdadeiro no desempenho ignorando volume ilusório criado pela Curva ROC na classe muito minoritária.  MAE: A métrica Regressora simples que afere erros de projeção de forma puramente linear resistente a outliers.  MSE: Métrica regressora que eleva erros ao quadrado para punir desvios absurdos de previsão.  R² Score: Percentual normalizado focando na variância explicada com êxito pelo modelo.
