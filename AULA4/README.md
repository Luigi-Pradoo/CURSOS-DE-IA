# 🧠 Aula 4 — Introdução ao Deep Learning

Este repositório reúne os conteúdos apresentados na **Aula 4**, introduzindo os principais conceitos de **Deep Learning**, desde o funcionamento do **Perceptron** até a construção de redes neurais utilizando **TensorFlow/Keras** e uma visão geral do **PyTorch**.

---

## 🎯 Objetivos da Aula

Ao concluir esta aula, você será capaz de:

- ✅ Entender o que é **Deep Learning** e sua importância na Inteligência Artificial.
- ✅ Compreender o funcionamento do **Perceptron**.
- ✅ Identificar a limitação do Perceptron no problema **XOR**.
- ✅ Entender a arquitetura de uma **MLP (Multilayer Perceptron)**.
- ✅ Conhecer o processo de **Forward Propagation** e **Backpropagation**.
- ✅ Diferenciar as principais **funções de ativação**.
- ✅ Escolher funções de perda e otimizadores adequados.
- ✅ Desenvolver modelos utilizando **TensorFlow/Keras**.
- ✅ Conhecer as principais características do **PyTorch**.
- ✅ Implementar uma rede neural para classificação utilizando o dataset **MNIST**.


3. Instale as dependências.

